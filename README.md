# TaskFlow

TaskFlow is a modern and responsive task management web application built with HTML, CSS, Bootstrap 4, and JavaScript.

It allows users to create, manage, search, filter, edit, complete, and delete tasks. Tasks are stored in the browser using LocalStorage.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Complete and undo tasks
- Search tasks by title
- Filter tasks by priority
- High, Medium, and Low priority badges
- Dynamic task counters
- Form validation
- Empty search result message
- LocalStorage support
- Responsive design
- Bootstrap-based UI
- Font Awesome icons

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4.6
- JavaScript
- Font Awesome
- LocalStorage
