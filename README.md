# TaskFlow

A modern and responsive task management web application built with HTML, CSS, Bootstrap 4, and JavaScript.

TaskFlow allows users to create, manage, search, filter, edit, complete, and delete tasks through a clean and user-friendly interface. Task data is stored in the browser using LocalStorage.

## ✨ Features

- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Search tasks by title
- Filter tasks by priority
- High, Medium, and Low priority indicators
- Dynamic task counters
- Form validation
- Empty search result message
- LocalStorage support
- Responsive design
- Mobile-friendly layout
- Bootstrap components and utilities
- Font Awesome icons

##  Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure |
| CSS3 | Custom styling |
| Bootstrap 4.6 | Responsive layout and UI components |
| JavaScript | Task management and application logic |
| LocalStorage | Persistent task data |
